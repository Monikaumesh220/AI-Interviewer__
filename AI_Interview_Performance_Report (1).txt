Question 5: Can you explain the concept of time complexity and what Big O notation represents using a simple sorting algorithm as an example?

Candidate Answer:
Time complexity measures how the execution time of an algorithm grows as the input size increases. Big O notation describes the growth rate of an algorithm.  For example, Bubble Sort compares adjacent elements and swaps them if they are in the wrong order. Its average and worst-case time complexity is O(n²) because it uses nested loops. If the input size doubles, the number of operations may increase roughly four times.  Common Big O examples are O(1) for constant time, O(n) for linear time, and O(n log n) for efficient sorting algorithms like Merge Sort.
